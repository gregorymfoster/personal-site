Welcome to my personal website! This is my first blog post written in MDX.

## What is this?

This is a simple personal website built with Next.js 15, featuring:

- A clean, minimal design inspired by great personal sites
- Blog posts written in MDX
- SEO optimization
- Fast performance

## Why MDX?

MDX allows me to write blog posts in Markdown while also using React components when needed. This gives me flexibility without sacrificing simplicity.

For example, I can write regular markdown like this list:

1. First item
2. Second item
3. Third item

And it just works!
